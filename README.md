# Unicornio Tango Weekend

A lightweight, multilingual event landing page for October 23–25, 2026 in Riga.

## Stack

- Static HTML
- CSS
- Vanilla JavaScript
- GitHub Pages

There are no dependencies, build tools or server processes.

## Add the milonga registration form

Open `script.js` and set the URL in the first line:

```js
const MILONGA_FORM_URL = "https://forms.gle/your-form";
```

The registration button will become active automatically.
